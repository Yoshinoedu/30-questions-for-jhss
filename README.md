# 英文法 STEP 30

中学英文法の基本30問で苦手を見つけ、無料の公式解説で学び直すWebアプリです。

## ファイル

- `index.html`：アプリ本体。CSS・JavaScript・問題データをすべて含みます。
- `README.md`：この説明書。
- `.nojekyll`：静的ファイルをそのまま公開するための空ファイル。

追加のインストール、ビルド、APIキーは不要です。

## GitHub Pagesで公開する方法

1. ZIPをダウンロードして展開します。ZIPそのものをアップロードしないでください。
2. GitHubで新しいリポジトリを作成します。無料プランではPublicを選択します。
3. リポジトリで **Add file → Upload files** を選択します。空のリポジトリでは **uploading an existing file** から進めます。
4. 展開したフォルダーの中の `index.html`、`README.md`、`.nojekyll` をアップロードし、**Commit changes** で保存します。
   - `index.html` がリポジトリの一番上にある状態にしてください。フォルダーごと入れて一段深くならないようにします。
   - `.nojekyll` が見えない場合も、このHTMLアプリは `index.html` のアップロードで使えます。
5. **Settings → Pages** を開きます。
6. **Source** を **Deploy from a branch** にします。
7. **Branch** を **main**、フォルダーを **/(root)** にして **Save** を押します。
8. 公開処理が終わると、Pages設定画面にURLが表示されます。そのURLを生徒に共有します。

公式手順：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

公開後は、閲覧者のChatGPTログインは不要です。
既存のサイトがある場合は、上書きを避けるため新しいリポジトリを使ってください。

## 学習機能

- 中学英文法30問・4択。選択肢の順序をランダム化。
- 「わからない・あとで復習」でスキップ可能。
- 回答後に正解と短い解説を表示。
- 誤答・スキップ時にベネッセ公式の無料公開解説へリンク。
- 診断結果、問題別の振り返り、苦手だけの解き直し。
- 同じブラウザーで途中再開。学習結果はテキスト保存可能。
- スマートフォン・PCの画面幅に対応。

## 記録と解説リンクについて

記録は各利用者のブラウザー内のlocalStorageに保存します。教員への自動送信やクラスの成績集約は行いません。別端末・別ブラウザーには自動同期されません。ブラウザーのデータ削除で消える場合があります。

問題とミニ解説は本アプリ用に作成したものです。外部解説は転載せず、ベネッセ公式の公開ページを別タブで開きます。本アプリはベネッセと提携していません。外部解説の閲覧にはインターネット接続が必要です。リンク先の内容・公開状態は今後変わる場合があります。リンク確認日：2026年11月10日。


## 動画リンク追加版（2026年11月10日）

誤答・スキップした問題のフィードバックと結果画面の問題詳細に「この文法の動画を見る」ボタンを追加しました。全30問に対応するeboard公式の授業動画視聴ページへ直接リンクしています。動画のタイトルも表示します。視聴ページを別タブで開き、再生ボタンを押して視聴した後、このアプリに戻って復習できます。文章の解説リンクも残しています。

動画は転載・ダウンロード・再配信せず、提供元の公式ページを開く方式です。NPO法人eboardの教材を使用し、本アプリと同団体に提携関係はありません。無料公開されている視聴ページを選定しています。学校のネットワークやフィルタリング設定により動画が再生できない場合があります。映像自体の全編再生は今回の動作確認の対象外です。

GitHubにアップロード済みの場合は、このZIPを展開して新しいindex.htmlを同じ場所にアップロードし、Commit changesで上書きしてください。以前の診断・復習記録は同じ公開URL・ブラウザーで引き継ぎます。

公式案内：https://info.eboard.jp/use
